**THT TV - XemTV** là ứng dụng xem truyền hình trực tuyến bản địa (Native Android Leanback & Touch UI), hỗ trợ hoàn hảo cho cả **Android TV, TV Box** và **Điện thoại Android**.

---

## 🌟 Tính Năng Nổi Bật

- **Tự động Cập Nhật Ứng Dụng (In-App Auto Update)**:
  - Tự động kiểm tra bản cập nhật mới nhất từ GitHub khi mở ứng dụng.
  - Hỗ trợ nút *Kiểm tra cập nhật* thủ công trong menu Cài đặt.
  - Tự động tải và cài đặt bản cập nhật trực tiếp trong ứng dụng.
- **Tự động Chuyển Server Dự Phòng (3.5s Watchdog Failover)**:
  - Khi luồng phát chậm hoặc quá 3.5 giây không phản hồi, ứng dụng tự động chuyển sang server kế tiếp (Server 2, Server 3, Server 4...).
- **453 Kênh Truyền Hình, Phim & Radio Tuyển Chọn**:
  - Nhóm kênh truyền hình Việt Nam đứng đầu (VTV, HTV, HTVC, VTVcab, SCTV, Địa phương).
  - Trọn bộ 11 kênh Giải Trí TV360 (360 Phim Việt, 360 K-Drama, 360 Anime...).
  - Trọn bộ 11 kênh Radio Zing MP3 chính thức.
  - Các luồng trực tiếp bóng đá, bình luận viên (COLA TV, GÀ VÀNG, KHÁN ĐÀI...).
- **Hệ Thống Lịch Phát Sóng (EPG) & Kho Logo Sắc Nét**:
  - Tích hợp trực tiếp nguồn EPG tốc độ cao và kho logo kênh truyền hình trực quan, sống động.
